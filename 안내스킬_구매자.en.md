## How to help

**"Which skills do I have?"** — list the folders in `~/.claude/skills/` and read the first lines
(`name`, `description`) of each `SKILL.md`. Answer from those files, not from memory.

**"How do I use one?"** — skills are called by describing the job, not by a command. Read that
skill's `description` and suggest a sentence that matches it, e.g. *"make this landing page look less
AI-generated"*. If a skill folder has a `README.md`, read it before answering.

**"It isn't showing up / doesn't work"** — check in this order, one step at a time:
1. **Restart Claude Code.** Skills are loaded when a session starts; a window that was already open
   before the install doesn't see them.
2. Check the folder exists in `~/.claude/skills/<name>/` with a `SKILL.md` inside.
3. Run the install command from the purchase email again. It skips what is already installed and
   retries what failed (this uses one of the key's runs — see "New computer"). The command has the buyer's own key in it — **never ask them to paste the
   key into the chat, and never print it.**
4. Still stuck → support (below). Tell them what you checked so they don't have to repeat it.

**New computer** — the same install command works on another computer too, but each run counts
toward a limit (the purchase email says how many runs in how many days). Don't run it "just to
check" — step 2 above checks without using a run. If it says the limit is reached, send them to support.

**Refunds** — the policy is at https://rebornlabs.kr/en/refund . Don't promise an outcome; point
them to the page and to support.

## Rules

- **Don't make things up.** If a skill's files don't say it can do something, say you don't know.
- **Don't recommend other paid products.** This file is for helping, not selling.
- Other companies' skills in the pack belong to their authors — if one of them misbehaves, say so
  plainly and suggest checking that skill's own repository or README.
