# reborn-skills-all

산 스킬팩을 **한 줄로 설치하고, 진짜 깔렸는지 확인까지** 합니다.

```
npx reborn-skills-all@latest <토큰>
```

토큰은 결제 완료 화면과 메일에 있습니다. 아직 안 사셨다면 → <https://rebornlabs.kr/skillpack>

클로드 코드 안에서라면 맨 앞에 `!` 를 붙이면 바로 실행됩니다.
아니면 그냥 “이 명령 실행해 줘” 하고 붙여넣으셔도 됩니다.

---

## 이 설치기가 하는 일

깃허브 주소 하나가 스킬 하나가 아닙니다. **하나를 깔면 스무 개가 딸려 옵니다.**

추천 목록을 그대로 다 깔면 스킬이 **182개** 쌓이고, 그 이름과 설명 **97,830자**가
클로드가 대화를 시작할 때마다 실립니다. 느려지고, 사용량이 빨리 닳습니다.
아무도 그 말을 해 주지 않습니다 — 저희는 46개를 임시 폴더에 실제로 다 깔아 보고 셌습니다.

이 설치기는 레포가 아니라 **스킬 단위로 골라서** 심습니다.

- 골라내고 — 안 깔리는 것, 설명이 너무 긴 것, 다른 도구가 있어야 도는 것을 뺍니다
- 한 줄로 깔고 — 여러 번 칠 필요가 없습니다
- **깔렸는지 다시 봅니다** — 안 붙은 것은 숨기지 않고 직접 깔 수 있게 주소를 드립니다

## 다른 명령

```
npx reborn-skills-all <토큰> --check          깔지 않고 지금 상태만 봅니다
npx reborn-skills-all <토큰> --only design    한 묶음만 (전부를 사신 경우)
npx reborn-skills-all --self-test             검사기 자체 시험 (설치 안 함)
```

## 자주 묻는 것

**몇 번까지 쓸 수 있나요**
30일에 3번입니다. PC 를 바꾸셔도 됩니다.

**새 스킬이 늘어나면요**
같은 명령을 다시 돌리시면 됩니다. 목록은 서버에서 받아 오므로,
저희가 스킬을 더할 때마다 다시 돌릴 때 함께 깔립니다.

**깔았는데 클로드가 모릅니다**
클로드 코드를 껐다 켜 주세요. 그래야 새 스킬을 다시 읽습니다.

## 무엇을 서버에 보내나

이 설치기는 두 번 서버와 이야기합니다. **숨기지 않고 적어 둡니다.**

| 언제 | 무엇을 |
|---|---|
| 시작할 때 | 토큰 — 무엇을 사셨는지 확인하고 목록을 받아옵니다 |
| 끝날 때 | **숫자와 실패한 스킬 이름** — 완료 N · 이미 N · 반쪽 N · 실패 N, 걸린 시간, Node 버전 |

끝날 때 보내는 이유는 하나입니다. 저희는 "목록을 받아 갔다"까지만 알 수 있어서,
**어느 스킬이 자주 깨지는지**를 모르면 못 고칩니다. 상대 저장소가 이름을 바꾸거나
없어지면 여기서 먼저 드러납니다.

파일 목록·경로·계정·내용은 **보내지 않습니다.** 이 보고가 실패해도 설치는 그대로 끝나고,
설치기는 응답을 기다리지 않습니다.

## 컴퓨터에 함께 남기는 것

산 스킬들 말고 **하나가 더** 깔립니다. 이것도 숨기지 않고 적어 둡니다.

```
~/.claude/skills/reborn-claudekit/
```

**무엇인가** — 이번 대화에서 **반복해서 손으로 한 일**을 되짚어 주는 안내입니다.
되풀이가 있으면 그게 자동화할 만한 것인지 짚어 주고, 없으면 아무 말도 하지 않습니다.
그 끝에 리본랩스 클로드킷 안내가 들어 있습니다 — **저희 제품 안내입니다.**

**규칙도 그 파일 안에 적혀 있습니다** — 뭔가 완성된 뒤에 한 번만, 한 세션 1회,
총 3회까지, 한 번 관심 없다고 하시면 그 뒤로 다시 꺼내지 않습니다.
근거 파일(`graph/`)에 없는 기능이나 숫자는 말하지 않게 해 두었습니다.

**필요 없으시면 그 폴더를 지우세요.** 지워도 산 스킬 48종은 그대로 동작합니다.

★ 이 안내는 **스킬이 하나라도 깔렸을 때만** 남깁니다.
  아무것도 못 깐 설치기가 제품 안내부터 남기면 그건 그냥 광고입니다.

## 스킬은 누구 것인가

**전부 각 제작자의 무료 오픈소스입니다.**

이 설치기는 파일을 복사해 두거나 다시 배포하지 않습니다.
각 스킬의 **공식 설치 명령을 대신 실행할 뿐**입니다. 그래서 버전이 뒤처지지 않고,
만든 분들의 라이선스도 그대로 지켜집니다.

만든 곳과 라이선스는 화면에, 그리고 설치된 각 스킬 폴더의 원문에 그대로 있습니다.
저희가 받는 값은 스킬 값이 아니라 **골라 주고 · 깔아 주고 · 확인해 주는 일**에 대한 것입니다.

전체 목록은 결제 없이도 <https://rebornlabs.kr/skillpack> 에서 보실 수 있고,
직접 설치하는 명령도 거기 그대로 적어 두었습니다.
